# PulseTrack

Plataforma personal de telemetría biométrica, entrenamiento, rutas GPX 2D/3D, nutrición e IA híbrida.

## Stack
- Frontend: Next.js 15, React 19, TypeScript, Tailwind CSS, MapLibre GL JS
- Base de datos: Supabase (Postgres 17, PostGIS, pgvector)
- ML / Backend: Python (FastAPI, Polars, PyTorch/XGBoost, SHAP, ONNX)
